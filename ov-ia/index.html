What moves and why

Each move below puts a screen next to the data it works on.

ScreenNowProposedWhy
Payer RatesOrganization and ConfigurationsConfigurationsThe same table currently shows in both places.
Network Status RulesAvatar menu, own itemConfigurationsIt is a rules table that changes how checks resolve, like payer mappings and rates. The page is titled Network Status Rules, but its menu item says Network Status.
GroupsWorkflows › Manage GroupsOrganization › GroupsThe Users tab already lists each person's groups. People and their groups belong on one screen.
Productivity exportOrganization pageWork QueueThe CSV reports on assignment activity, which is work queue data.
Work QueuePolicy Assignment, Assigned PoliciesOne view, Unassigned and Assigned tabsBoth pages show the same columns and differ only by assignee. Their names are close enough that people open the wrong one.
SearchReports › SearchFilters panel on each reportIt filters the same checks every report already filters.
IntegrationsTop navConfigurations › IntegrationsConnecting Candid or an EHR is set up once.
ERA uploadIntegrations › Upload ERAInsights › ERA, plus Configurations › IntegrationsPractices on manual CSV upload can do it any time they want. The upload action sits on the tab that shows ERA results, and the setup stays with the other integrations.
Organization tabOrganization › OrganizationOrganization › DetailsThe first tab repeats its parent's name.
Help & SupportAvatar menuAvatar menu, marked externalIt opens the Zendesk help center outside the app.

ERA upload

The Candid integration is a one-time setup. Manual CSV upload is on the practice's own schedule, and they can do it any time.

Setup moves to Configurations. Practices that upload manually get the upload action on Insights › ERA, next to the results it feeds.
